🚀 QUICK START
════════════════════════════════════════════════════════════════════════════════

1. Install Dependencies:
   pnpm install

2. Start Development Server:
   pnpm dev

3. Open Browser:
   http://localhost:3000

4. Set Up Testnet Wallet:
   • Download Freighter or use Albedo
   • Fund with testnet XLM: curl "https://friendbot.stellar.org/?addr=YOUR_ADDRESS"

5. Make Your First Payment:
   • Click "Connect Wallet"
   • Enter amount (e.g., 100 XLM)
   • Select source/destination assets
   • Click "Get Best Rate"
   • Review and select optimal path

🔄 WORKFLOW: From Quote to Payment
════════════════════════════════════════════════════════════════════════════════

1. User enters payment details
         ↓
2. System queries Horizon API for pairs
         ↓
3. PathFinder evaluates multiple routes
         ↓
4. QuoteDisplay shows options with fees
         ↓
5. User selects optimal path
         ↓
6. PathPaymentBuilder constructs transaction
         ↓
7. WalletManager signs with user's wallet
         ↓
8. Transaction submitted to Stellar network
         ↓
9. System polls for confirmation (3-5s)
         ↓
10. TransactionMonitor displays result
         ↓
11. User sees savings vs traditional method

💡 KEY INSIGHTS FROM DEVELOPMENT
════════════════════════════════════════════════════════════════════════════════

1. Stellar's PathPaymentStrictReceive is perfect for this use case
   → Ensures recipient gets exactly the amount they expect

2. Soroban contracts enable trustless execution
   → Users don't have to manually execute each step

3. Multiple paths critical for cost optimization
   → Can save 30-50% by using alternative routes

4. Caching dramatically improves UX
   → Reduces API calls 90% for repeated queries

5. Non-custodial design is essential
   → Users maintain control of private keys
